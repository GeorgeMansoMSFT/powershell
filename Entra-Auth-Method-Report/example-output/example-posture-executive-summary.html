How to read this report

Registered versus observed

Registered strength is the highest-scoring method currently reported for a user. Explicit observation is limited to successful interactive sign-ins that returned a classifiable authentication step in this report window.

Evidence caveat

A missing explicit method does not mean that a user did not authenticate or did not use MFA. Existing sessions and token claims can satisfy a requirement without a fresh factor in that event.
