# Example output

These files show the expected shape of the Entra Authentication Posture report
and its executive HTML and optional workbook deliverables.

Every identity, ID, device name, IP address, and authentication event in this
folder is synthetic. The figures and report layout are representative of a
one-day example run, but they do not describe a real customer tenant.

- `example-posture.csv` - per-user posture report.
- `example-posture-summary.csv` - tier distribution and evidence coverage.
- `example-posture-evidence.csv` - synthetic, restricted evidence example.
- `example-posture-executive-summary.html` - portable, aggregate-only executive summary.
- `example-posture.xlsx` - packaged operations workbook.

The evidence file and the Evidence - Restricted worksheet model sensitive
authentication telemetry. Restrict access to those files in real deployments.
